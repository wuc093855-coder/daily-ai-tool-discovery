Methodology

每日四步工作流

01

公开来源扫描

采集 GitHub Trending、Product Hunt 官方 Feed 与 Hugging Face 公共 Hub API。

02

相关性与去重

使用名称、描述、标签与 URL 判断 AI 相关性，并规范化工具身份。

03

多维评分

综合实用性、热度、新鲜度、产品完整度与商业价值，避免只看单一热度。

04

中文信息整理

生成结构化中文摘要，缺失的价格、许可证和指标保持为空，不虚构。
